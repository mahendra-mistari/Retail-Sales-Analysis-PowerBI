# Retail Sales Analysis Dashboard – Power BI

## Project Overview
An interactive Power BI dashboard developed to analyse retail business performance across sales, profitability, products, customers, stores and returns.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Excel

## Dataset
A synthetic retail dataset containing:
- 300 Customers
- 110 Products
- 12 Stores
- 2,500 Orders
- 6,080 Order Details
- 252 Returns

## Dashboard Pages

1. **Executive Overview** – Overall sales, profit, margin, orders and business performance.
2. **Product Analysis** – Product sales, profitability and category performance.
3. **Customer Analysis** – Customer contribution, segments and purchasing behaviour.
4. **Store & Returns Analysis** – Store performance, returned quantities and return rates.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value (AOV)
- Total Customers
- Return Rate

## Key Features
- Interactive slicers and filters
- DAX-based business calculations
- KPI cards and analytical charts
- Top 5 product analysis
- Top 10 customer analysis
- Drill-through navigation
- Multi-page interactive reporting

## Business Objectives
- Evaluate sales and profitability.
- Identify high-performing products and stores.
- Understand customer contribution.
- Monitor product returns.
- Support data-driven business decisions.
